### Exercise 1 – Publish the Agent

Testing and publishing agents in Microsoft Copilot Studio ensures that your virtual agent is functional and accessible across various platforms such as the web, Microsoft Teams, and Microsoft 365 Copilot. This phase is essential for validating agent performance and providing a seamless end-user experience.

#### Task 1.1 – Publish the Agent

1. Navigate to the [Microsoft Copilot Studio](https://copilotstudio.microsoft.com) portal and ensure you are in the appropriate environment.

2. Select **Agents** from the left navigation pane.

3. Select the **Real Estate Booking Service** agent you created in the earlier lab.

4. Select **Publish**.

5. Select **Force newest version**, and then select **Publish**. Wait a few seconds until the agent is published.

6. Once the agent is published, select **Channels** from the top menu bar.

    ![Screenshot](../media/aaa2.png)

7. Select **Demo website** > **Open demo website**. A new webpage will open.

8. Enter `I want to book a real estate showing` and press **Enter**.

9. Enter your name and email, and select **Yes** when prompted.

10. Select **House** as the property type.

11. Enter `3 bedrooms`.

12. Enter `Tomorrow 3:00 PM` as the date and time.

13. Select **Yes**.

14. Select any rating.

15. Select **No**.

    ![Screenshot](../media/aa3.png)
